# Himachal on a Budget - Landing Page

A simple, single-page HTML and CSS landing page designed to serve as a welcome portal for a digital product, specifically tailored for a student travel guide. 

## Overview
This template features a clean dark theme, custom typography, and a CSS/SVG-based hero banner. It is structured to provide users with an overview of what they are about to access, instructions on how to use the guide, and a final call-to-action button to open the actual content (like a Notion template).

## Features
* **Zero Dependencies:** Built entirely with plain HTML and CSS. No JavaScript or heavy frameworks required.
* **Custom SVG Art:** Includes a lightweight, purely mathematical SVG header depicting a mountain range and night sky.
* **Structured Content:** Pre-built, easily editable sections for an introductory callout, a "What's Inside" list, step-by-step instructions, and an access link.
* **Web Fonts:** Integrated with Google Fonts (Cormorant Garamond, DM Mono, and DM Sans) for premium typography.

## Usage
1. Clone or download the repository.
2. Open the `index.html` file in any modern web browser to view the page.
3. Because it is a static file, it can be hosted for free on platforms like GitHub Pages, Netlify, Vercel, or standard shared hosting.

## Customization
You can modify the template by opening `index.html` in any text editor. 
* **Text & Links:** Scroll down to the `<body>` tag to swap out the placeholder text. The final destination link can be updated in the `<a class="locked-link" href="...">` tag near the bottom of the document.
* **Colors:** The color palette is defined at the top of the `<style>` block and can be adjusted to fit your brand.
